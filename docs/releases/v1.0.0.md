# RMGuard v1.0.0

**Release Date**: 2026-05-24

First stable release of RMGuard.

## Installation

### Install From Source

```bash
git clone -b v1.0.0 https://github.com/Happyuky7/RMGUARD-Linux.git
cd RMGUARD-Linux
chmod +x scripts/*.sh src/rmguard src/rmguard-cli test/rmguard_test.sh
sudo bash ./scripts/install.sh
source /etc/profile
rmguard --status
```

### Install .deb Package

Use this if the `.deb` asset has been uploaded to the release.

```bash
wget https://github.com/Happyuky7/RMGUARD-Linux/releases/download/v1.0.0/rmguard_1.0.0_all.deb
sudo apt install ./rmguard_1.0.0_all.deb
source /etc/profile
rmguard --status
```

To build the `.deb` on a Linux machine:

```bash
bash ./scripts/package.sh 1.0.0
```

## Highlights

- Blocks dangerous interactive `rm` usage against `/` and top-level paths.
- Keeps `/tmp` and `/var/tmp` allowed by default through configuration.
- Avoids replacing `/bin/rm`; RMGuard is loaded as a shell function.
- Supports deliberate bypass with `RM_GUARD=0` or `--no-guard`.
- Includes CLI status, version, help, and update-check commands.
- Includes FAQ, command reference, GitHub Pages documentation, and translated READMEs.

## Known Limitations

- Scripts using `/bin/rm` directly or `command rm` bypass RMGuard.
- Protection applies only where the shell function is loaded.
- RMGuard is a safety layer, not a backup or recovery system.

## Validation Checklist

- Install from source with `sudo bash ./scripts/install.sh`.
- Run `source /etc/profile`.
- Confirm `rmguard --version` prints `1.0.0`.
- Confirm `rmguard --status` reports the installed files.
- Confirm `rmguard --status` reports ACTIVE.
- Confirm `rm -rf /etc` is blocked.
- Confirm deletion inside `/tmp` still works, such as `/tmp/rmguard-test`.
