RMGuard GitHub Pages Setup

The RMGuard website is served from the docs/ directory.

Recommended Settings

  1. Open the GitHub repository settings.
  2. Go to Pages.
  3. Set the source to the master branch.
  4. Set the folder to /docs.
  5. Save and wait for GitHub Pages to deploy.

Public Pages

  • index.html is the landing page.
  • GETTING_STARTED.html is the install guide.
  • COMMANDS.html is the command reference.
  • FAQ.html is the FAQ.
  • releases/v1.0.0.html is the stable release page.

Markdown Files

The .md files stay in the repository as source documentation. The public website links to the matching .html files so the pages load with the RMGuard stylesheet.
