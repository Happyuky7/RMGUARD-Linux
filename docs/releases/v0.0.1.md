# rmguard v0.0.1

**Release Date**: 2026-05-24

Initial public pre-release for testing rmguard before the `1.0.0` release.

## Installation

### Install .deb Package

```bash
wget https://github.com/Happyuky7/RMGUARD-Linux/releases/download/v0.0.1/rmguard_0.0.1_all.deb
sudo apt install ./rmguard_0.0.1_all.deb
source /etc/profile
rmguard --status
```

### Install From Source

```bash
git clone -b v0.0.1 https://github.com/Happyuky7/RMGUARD-Linux.git
cd RMGUARD-Linux
sudo ./scripts/install.sh
source /etc/profile
rmguard --status
```

## Highlights

- Blocks dangerous interactive `rm` usage against `/` and top-level paths.
- Keeps `/tmp` and `/var/tmp` allowed by default.
- Avoids replacing `/bin/rm`; rmguard is loaded as a shell function.
- Supports deliberate bypass with `RM_GUARD=0` or `--no-guard`.
- Includes CLI status, version, help, and update-check commands.
- Includes manual install, uninstall, release, and package scripts.

## Compatibility

- Bash interactive shells
- Debian/Ubuntu-style systems
- Any Linux system with `/bin/rm`, `bash`, and standard coreutils

## Known Limitations

- Scripts using `/bin/rm` directly or `command rm` bypass rmguard.
- Protection applies only where the shell function is loaded.
- The update checker depends on GitHub releases being published with tags.

## Validation Checklist

- Build package with `./scripts/package.sh 0.0.1`.
- Install package with `sudo apt install ./build/rmguard_0.0.1_all.deb`.
- Run `source /etc/profile`.
- Confirm `rmguard --version` prints `0.0.1`.
- Confirm `rmguard --status` reports the installed files.
- Confirm `rm -rf /etc` is blocked.
- Confirm `/tmp` deletion still works.
