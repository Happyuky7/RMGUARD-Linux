# RMGuard v0.0.2

**Release Date**: 2026-05-24

Patch pre-release after the first Linux install test of `v0.0.1`.

## Installation

### Install From Source

```bash
git clone -b v0.0.2 https://github.com/Happyuky7/RMGUARD-Linux.git
cd RMGUARD-Linux
chmod +x scripts/*.sh src/rmguard src/rmguard-cli test/rmguard_test.sh
sudo bash ./scripts/install.sh
source /etc/profile
rmguard --status
```

### Install .deb Package

Use this only if the `.deb` asset has been uploaded to the release.

```bash
wget https://github.com/Happyuky7/RMGUARD-Linux/releases/download/v0.0.2/rmguard_0.0.2_all.deb
sudo apt install ./rmguard_0.0.2_all.deb
source /etc/profile
rmguard --status
```

To build the `.deb` on a Linux machine:

```bash
bash ./scripts/package.sh 0.0.2
```

## What's Fixed

- Fixes `/etc/profile.d/rmguard.sh` when the shell already has an `rm` alias.
- Fixes `rmguard --status` by exporting a shell-loaded marker from
  `/etc/profile.d/rmguard.sh`.
- Documents `chmod +x` after cloning from source.
- Uses `sudo bash ./scripts/install.sh` in docs, so install does not depend on
  executable bits being preserved.

## Highlights

- Blocks dangerous interactive `rm` usage against `/` and top-level paths.
- Keeps `/tmp` and `/var/tmp` allowed by default.
- Avoids replacing `/bin/rm`; rmguard is loaded as a shell function.
- Supports deliberate bypass with `RM_GUARD=0` or `--no-guard`.
- Includes CLI status, version, help, and update-check commands.

## Known Limitations

- Scripts using `/bin/rm` directly or `command rm` bypass rmguard.
- Protection applies only where the shell function is loaded.
- The update checker depends on GitHub releases being published with tags.

## Validation Checklist

- Install from source with `sudo bash ./scripts/install.sh`.
- Run `source /etc/profile`.
- Confirm `rmguard --version` prints `0.0.2`.
- Confirm `rmguard --status` reports the installed files.
- Confirm `rmguard --status` reports ACTIVE.
- Confirm `rm -rf /etc` is blocked.
- Confirm `/tmp` deletion still works.
