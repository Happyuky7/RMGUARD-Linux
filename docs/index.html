Linux rm safety guard

RMGuard

A small protection layer for interactive shells that blocks dangerous top-level delete commands while keeping normal `rm` usage familiar.

Install v1.0.0 Read the guide Sponsor <3

Install From Source

Install the latest stable RMGuard release from the tagged source.

bash 
$ git clone -b v1.0.0 https://github.com/Happyuky7/RMGUARD-Linux.git
$ cd RMGUARD-Linux
$ chmod +x scripts/*.sh src/rmguard src/rmguard-cli test/rmguard_test.sh
$ sudo bash ./scripts/install.sh
$ source /etc/profile
$ rmguard --status

What RMGuard Protects

Top-Level Paths

Blocks commands such as `rm -rf /etc`, `rm -rf /bin`, and `rm -rf /`.

Interactive Shells

Loads through `/etc/profile.d` so system scripts and services stay untouched.

Explicit Bypass

Supports deliberate overrides with `RM_GUARD=0` or `--no-guard`.
